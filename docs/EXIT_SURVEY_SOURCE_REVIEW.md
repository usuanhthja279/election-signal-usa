# Exit-survey source review

No authorized exit-poll dataset is connected. [Roper Center](https://ropercenter.cornell.edu/exit-polls/us-national-election-day-exit-polls) catalogs National Election Pool exit surveys; access and redistribution rights have not been established. Do not copy media tables or assume public page visibility grants reuse rights.

[AP VoteCast](https://apnorc.org/projects/ap-votecast-2024-general-election/) publishes 2024 public-use files and methodology. It is a phone/web voter survey conducted October 28–November 5, not a traditional in-person exit poll. Its redistribution terms and weighted tabulation pipeline have not been verified here; it must not be silently displayed as an exit poll. A properly labeled separate voter-survey integration would require rights review, questionnaire, weighting, sample and release metadata, and tested calculations.
