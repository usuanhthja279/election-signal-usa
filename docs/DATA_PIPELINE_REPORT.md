## House results and source-rights continuation

A separate distributor, Election Data, publishes a versioned CC0 distribution of MIT Election Data and Science Lab House V15: https://electiondata.dev/datasets/house-results/ . Its metadata identifies the MIT release and its own upstream hash. This project imports the distributor's transformed CSV, not the inaccessible original Harvard file; it is attributed to both. The pinned distribution URL is `https://api.electiondata.dev/v1/house-results@2026-10-26.cc2e247a45/download/house-results.csv`, SHA-256 `38db9d28dc4d3e039de97c89aedb921ca5f57dd137baf527c937b76bc8760214`. Both unversioned and versioned downloads matched that SHA-256 on 2026-11-02. One sample, 2024 TX-07, agrees with the U.S. House Clerk publication https://clerk.house.gov/member_info/electionInfo/2024/statistics2024.pdf; this spot check is not an independent audit of the whole file.

The importer accepts only that exact file, inserts 2,628 source ballot lines from 870 regular 2022/2024 voting-district contests (435 each), retains four missing counts as null and preserves party/fusion lines separately. It excludes delegate contests, special elections, runoffs, earlier years and blank/overvote/undervote rows. It does not infer 2026 boundaries or county allocations and does not assert independent certification. The UI labels ballot lines so multiple party lines are not mistaken for distinct candidates. Historical district scope no longer requires membership in a 2026 district registry; missing historical scopes remain unavailable.

For an intentionally configured local database, download the pinned CSV to a path chosen by the operator and run `scripts/Import-HouseResults.ps1 -SourceFile <path>` after setting `ELECTION_DB_URL`, `ELECTION_DB_USER`, and `ELECTION_DB_PASSWORD`. The command runs Flyway against that configured database; it does not create or choose one. This work did not modify the existing user database. The raw source file is stored in an ignored local runtime folder and is not committed to Git.

A disposable PostgreSQL run with `ELECTION_VERIFY_HOUSE_PATH`, `ELECTION_VERIFY_MEDSL_PATH`, and `ELECTION_VERIFY_POLLINGFORECAST=true` passed 31 tests with no skips.
