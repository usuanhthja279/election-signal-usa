# Historical import guide

The source ledger is `history_sources.csv`. The first implemented path imports the pinned, CC0 [MIT U.S. Senate statewide 1976–2024 V8 original CSV](https://doi.org/10.7910/DVN/PEJ5QU). Download the original file from `https://dataverse.harvard.edu/api/access/datafile/13887039?format=original` to `.runtime/history-sources/senate-v8-original.csv`. Harvard’s published MD5 is `0f8b51cf0f77a2ef0bff992f7a64d1b4`; the importer requires SHA-256 `6f745db1b4a0026ad837e74428f9ed6f3f77fa51eb6f858b58ebdbc186fdb3bd`. Only 2022/2024 general-election rows marked unofficial=False are imported. MIT's statement is not treated as independently checked certification. Contest sums must reconcile; original bytes are retained. Special races stay separate. Import is idempotent.

For an existing intended local database, configure `ELECTION_DB_URL`, `ELECTION_DB_USER` and `ELECTION_DB_PASSWORD`, then run `scripts/Import-MedslSenate.ps1 -SourceFile <path>`. Flyway migrates that specified database; do not point this command at a database without intending that change.

To run the self-contained local evidence preview, use `scripts/Start-DataPreview.ps1`. It creates a separate PostgreSQL cluster under `.runtime/data-preview`, binds it to localhost port 55460, protects its generated password with the current Windows user's DPAPI, imports the pinned MIT source and explicitly licensed Polling Forecast snapshots, and starts the local profile. Use `scripts/Stop-DataPreview.ps1` to stop the owned preview and database; data remain on disk. No live election results or exit surveys are imported. The original V7 and demo fixtures remain separate.

The earlier `Import-History.ps1` only stages files. House, Governor and county imports need independently reviewed releases; Harvard's House file currently requires a guestbook response. Do not substitute presidential totals for another office or county totals for district results.
