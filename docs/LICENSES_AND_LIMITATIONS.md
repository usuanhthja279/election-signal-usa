# Licensing, Attribution and Limitations

- The original UI markup and demo layout were developed for this project. The reference geographic SVG path collection is a pre-existing prototype artifact; its vintage/attribution/licensing has **not been independently verified for redistribution or production**. Keep it for local development only until a verified official Census data import replaces it.
- No live AP, DDHQ, civicAPI, pollster, exit-poll, state authority or MIT data has been imported or redistributed in the delivered Phase 0 bundle.
- Historical datasets and source links listed in docs are research candidates, not a claim of licensed ingestion or full national coverage.
- No 2026 House district winner can be established from county colors; production requires legal district boundaries and district-specific vote data.
- `data/demo` is intentionally fictional. UI demos may show win-probability concepts only labeled as simulated; no model is trained.
- The project is a native-local demonstration and not production-hardened or suited for public election results hosting.
