# V14 prototype and React application comparison

Review date: 2026-11-02. This is a parity assessment, not approval of the V14 prototype's fictional election data or geography. The supplied V14 HTML and the current React source were compared. The approved V7 and reference screenshots were not edited.

## Confirmed bugs

1. **Wrong exit survey year in page chips.** Open `/?mode=exit&year=2024&state=TX`: the header shows survey cycle 2024, but the state card says `TX · 2026`. The county page similarly says `2026 · REFERENCE`. Reproduced in Chromium at 320, 390, 768, 1024, 1440 and 1920 px for the state page, and at 1440 px for county. Render the selected survey year consistently. See `frontend/src/components/ExploreViews.tsx` and `frontend/src/components/ElectionShell.tsx`.
2. **Sidebar office selection loses the state.** Open `/?mode=history&year=2000&state=TX&office=senate`, then select US House in the sidebar. The URL drops `state=TX` and goes to the national House page. Retain the selected state when switching office from a state context, and clear only an incompatible district. See `ElectionShell.tsx` sidebar handler.
3. **Exit mode on the House county inspector displays result-specific messaging.** Open the Harris House county inspector and switch to Exit Polls. It remains on the geography preview and says that 2026 district results are not loaded, without explaining survey unavailability. Supply exit-survey-specific language and assess whether this geography-only route should remain accessible in that mode. See `HouseCountyDistrictPreview.tsx`.
4. **Built-in browser rendering needs investigation.** A previous review reached the local app in the ChatGPT browser but showed an unstyled page. The separate development preview opened in the built-in browser during this review; styled visual parity there was not verified. Do not treat this as a confirmed application CSS defect until the browser's asset loading is investigated.
