# Polling licenses

Source records default to `UNREVIEWED` and `redistribution_allowed=false`. Public reads require an approved review and explicit redistribution permission per source. Source URL, license ID, attribution and evidence are stored separately for each source. A database flag or `isTestData=false` is an operator attestation, not proof of rights or authenticity.

Polling Forecast describes its own forecasts as CC BY 4.0 with attribution, but says underlying poll figures have separate rights. See [the source inventory](PHASE_3_SOURCE_INVENTORY.md). The explicit manual forecast importer records the documented CC BY 4.0 rights for the provider-owned forecasts. A live integration test imported them only into a disposable database. No real survey source has been approved or imported.
